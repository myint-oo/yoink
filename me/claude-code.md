# Claude Code

Install with the native installer (lands in `~/.local/bin/claude`).

Settings (`~/.claude/settings.json`):
- Vim editor mode, `jj` in insert mode is Esc.
- Effort level xhigh, fullscreen TUI, theme auto.
- Push notifications on for agent updates and when input is needed.
- Plugins: add the marketplaces `obra/superpowers-marketplace`, `warpdotdev/claude-code-warp` and `DietrichGebert/ponytail`; enable `superpowers@superpowers-marketplace` and `warp@claude-code-warp`.
- Status line: ponytail's `hooks/ponytail-statusline.sh` (run with bash from the ponytail plugin folder).
