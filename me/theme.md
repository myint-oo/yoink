# Theme

- Font: JetBrains Mono, size 15, ligatures on. Use Symbols Nerd Font Mono as the fallback for icons.
- Fonts to install: JetBrains Mono Nerd Font, Monaspace, Symbols Only Nerd Font (Homebrew casks `font-jetbrains-mono-nerd-font`, `font-monaspace`, `font-symbols-only-nerd-font`).
- Line height: roomy (Neovide uses 16px of extra line spacing).
- Color scheme: follow the OS light/dark mode automatically.
  - Light: GitHub Light.
  - Dark: no shared default; each tool file names its own dark theme.
- Comments in italics.
